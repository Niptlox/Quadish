# Quadish

2D-песочница на pygame: газовый гигант, копай, строй, крафть и спускайся к ядру.

## Запуск

```bash
pip install -r requirements.txt
python game.py
```

Сборка в exe, тесты и бенчмарки — см. [BUILDING.md](BUILDING.md).
Полная справка по управлению — в игре: **[F1]** или кнопка «Справка» в меню
(также в [data/translations/help_ru.md](data/translations/help_ru.md)).

## Управление (кратко)

- **[A]/[D]** или стрелки — движение, **[Пробел]** — прыжок (до 2 в воздухе,
  зелья прыжков дают до 5), **[S]** — присесть
- **[ЛКМ]** — копать / атаковать, **[ПКМ]** — поставить блок / использовать / съесть
- **[E]** — инвентарь и рецепты, **[Q]** — выбросить предметы из активной ячейки,
  колесо мыши или **[1]–[0]** — выбор ячейки
- **[Ctrl+S]** — сохранить мир (автосохранение каждые 5 минут),
  **[Ctrl+T]** — телепорт домой, **[Ctrl+R]** — случайный телепорт
- **[Esc]** — пауза, **[F1]** — справка, **[Alt+C]** — скриншот

Творческий режим: **[Alt+J]** — вкл/выкл, **[Alt+Пробел]** — полёт,
**[Alt+X]/[Alt+Z]** — перемотка времени на 1/10 минут.
