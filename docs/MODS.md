# Модификации (моды)

Мод добавляет в игру блоки, предметы и существа без правок кода. Всё
описывается одним файлом `mod.json`; спрайты можно либо рисовать цветом
(процедурно), либо положить свои PNG рядом.

## Куда положить

```
data/modifications/
  мой_мод/
    mod.json          ← обязательный файл
    my_block.png      ← необязательно, свои спрайты
```

Папка `data/` целиком попадает в собранную игру, так что мод работает и в
exe-версии — достаточно положить папку рядом с `Quadish.exe`.

Включить/выключить загрузку модов: **Настройки → Модификации**. В той же
строке видно, сколько модов загрузилось и были ли ошибки. Смена настройки
требует перезапуска — контент регистрируется один раз при старте.

Если мод описан неверно, игра **не падает**: мод пропускается, причина
пишется в консоль и в счётчик ошибок в настройках. Один плохой мод не
ломает остальные.

## Минимальный пример

```json
{
  "name": "Мой мод",
  "version": "1.0",
  "blocks": [
    {"id": 2001, "name": "Лазурный камень", "color": "#38BDF8"}
  ]
}
```

## Поля

### Общее

| Поле | Обязательно | Описание |
|------|-------------|----------|
| `name` | нет | Имя мода (по умолчанию — имя папки) |
| `version` | нет | Версия, по умолчанию `"1.0"` |
| `author` | нет | Автор |
| `blocks` | — | Блоки, которые можно поставить в мире |
| `items` | — | Предметы (поставить нельзя, только в инвентаре) |
| `creatures` | — | Существа |

Нужен хотя бы один блок, предмет или существо.

### Блоки и предметы

| Поле | По умолчанию | Описание |
|------|--------------|----------|
| `id` | обязательно | Уникальный номер, **от 2000** (ниже — занято базовой игрой) |
| `name` | обязательно | Название в инвентаре |
| `color` | — | Цвет `"#RRGGBB"` или `[r, g, b]` — спрайт рисуется сам |
| `sprite` | — | Путь к PNG внутри папки мода (вместо `color`) |
| `animation` | — | Анимация, см. ниже (вместо `color`/`sprite`) |
| `solidity` | `30` | Прочность: сколько нужно копать |
| `physical` | блок: `true`, предмет: `false` | Нельзя пройти сквозь |
| `eat` | — | Если задано — предмет съедобен и лечит на столько |
| `drops` | сам блок | Что выпадает: `[[id, количество, шанс], ...]` |
| `recipe` | — | Из чего крафтится: `[[id, количество], ...]` |
| `recipe_count` | `1` | Сколько получается за один крафт |

Количество — число (`3`) или диапазон (`[1, 3]`). Шанс — от 0 до 1
(необязателен, по умолчанию 1 — всегда).

В рецепте количество `-1` означает «предмет должен быть рядом, но не
тратится» — так работают верстак (`121`) и котёл (`125`):

```json
"recipe": [[2101, 4], [121, -1]]
```

### Анимация блока

```json
"animation": {"colors": ["#15803D", "#22C55E", "#4ADE80"], "speed": 4}
```

или из файлов:

```json
"animation": {"frames": ["f0.png", "f1.png", "f2.png"], "speed": 8}
```

`speed` — кадров в секунду. Нужно минимум 2 кадра. В инвентаре
показывается первый кадр.

### Существа

| Поле | По умолчанию | Описание |
|------|--------------|----------|
| `id_name` | обязательно | Латинский идентификатор, например `AzureSlime` |
| `name` | обязательно | Название |
| `base` | `"Slime"` | Чьё поведение взять (см. список ниже) |
| `color` | `"#38BDF8"` | Цвет |
| `lives` | `20` | Здоровье |
| `damage` | `0` | Урон игроку |
| `enemy` | `damage > 0` | Нападает ли |
| `size` | `[32, 32]` | Размер в пикселях |
| `speed` | `3` | Скорость передвижения |
| `drops` | — | Что выпадает после смерти |
| `spawn` | зона `surface` | Где спавнится, см. ниже |

`base` задаёт готовое поведение: `Slime` (прыгает), `Wolf` (ходит и
агрится на игрока), `Cow`, `Snake`, `Imp`, `Scorpion`, `Rabbit`, `Deer`,
`Fox`, `Camel`, `Penguin`, `Boar`, `Crab`, `Bat`, `StoneGolem`,
`SpaceDrifter`.

```json
"spawn": {"zone": "surface", "biomes": [1, 2, 4], "weight": 4}
```

* `zone` — `surface` (поверхность), `caves` (глубокие пещеры),
  `hell` (ад), `space` (космос).
* `biomes` — номера биомов, только для `surface`. Без этого поля —
  любой биом. `0` пустыня, `1` саванна, `2` тропики, `3` тундра,
  `4` сезонный лес, `5` джунгли, `6` лес, `7` влажный лес, `8` тайга,
  `9` ад.
* `weight` — вес в жеребьёвке спавна. Для сравнения: обычный слайм
  весит 10–20, редкие звери — 2–6.

Существа мода **добавляются** к обычным мобам биома, а не заменяют их.

## Полный пример

Живой рабочий пример лежит в `data/modifications/first/mod.json`:
блок с крафтом и выпадением, анимированный блок, съедобный предмет и
существо со спавном по биомам.

## Ограничения

* Мод не может добавлять новые механики (только контент по образцу
  существующего) и не может выполнять свой код — `mod.json` это данные.
* Если убрать (или выключить) мод, мир, где живут его существа, не
  откроется — сохранение ссылается на класс существа по имени. Игра при
  этом не падает и пишет «включите мод, с которым он создан»; достаточно
  вернуть мод на место. Прежде чем удалять мод насовсем, лучше скопировать
  папку `data/maps`.
* Инструменты (кирки, мечи) моды пока не добавляют.
